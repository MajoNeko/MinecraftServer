# Minecraft Server (Docker)

This projects explain how to host a Minecraft server (Java edition) running inside a Docker Container using Docker Compose. It provides a reliable, portable and reproducible server environment to be run on a cloud VM.

## Prerequisites

If you don't already have it installed, it is recommended to install Docker Engine and Docker Compose. You can download and follow installation instructions here: <https://docs.docker.com/desktop/setup/install/windows-install/> (on windows)
Make sure your host also has them installed.

## Quickstart

1. Make sure you have the server.jar in the 'assets/' folder (or a valid download URL in the Dockerfile). It can be downloaded from <https://www.minecraft.net/en-us/download/server>

2. Create .env file

```bash
cp example.env .env 
```

3. Start the server

```bash
docker compose up -d
```

4. Verify container is running

```bash
docker ps
```

5. Your server will now be reachable under: <CLOUD_VM_IP>:<SERVER_PORT>

## Usage

### Steps

1. Clone the repository and place the 'server.jar' in the assets folder (if not already there).
2. Start the server by running the following command:

```bash
docker compose up -d
```

3. To check if it started correctly use the following command:

```bash
docker compose ps
docker logs mc-server
```

4. Connect in Minecraft by running multiplayer - Add Server localhost:25565

### Configuration

The server behaviour is controlled in three layers:
    - The Dockerfile: defines the base image, intalled packageds and the default startup command.
    - Environment variables: set in "docker-compose.yaml" (or the .env file) under the mc-server service. These override defaults at runtime. To change a value, edit the variable and restart:
    ```bash
    docker compose up -d
    ```
    - "server.properties": generated by the server on first start inside the mounted volume, You can edit this file directly for fine-grained control.

### Modifying Behavior

- To change the minecraft version replace the assets/server.jar with a different version and rebuild using:

    ```bash
    docker compose build
    ```

- To enable the whitelist settings, change the WHITELIST variable to  - WHITELIST: "true" in Compose (or in the .env file), restart, then add players via the server console:

    ```bash
    whitelist add "username"
    ```

or by editing the whitelist.json in the volume.

- For larger worlds, you can modify the MEMORY variable
- To change the server port you can update the left side of "25565:25565" in Compose (eg: 25566:25565)

### Testing the Server

You can test the server using the [MC-Status](https://github.com/py-mine/mcstatus.git) Python tool.

``` bash
# 1. Clone mcstatus repository
git clone https://github.com/py-mine/mcstatus.git
cd mcstatus

# 2. Create and activate Python virtual environment
python -m venv venv
.\venv\Scripts\activate.ps1   # PowerShell

# 3. Install dependencies
pip install -r requirements.txt
# or:
pip install mcstatus

# 4. Check server status
mcstatus <CLOUD_VM_IP>:<EXAMPLE_PORT_25565> status

# Example output:
version: Java 1.21.8 (protocol 772)
motd: A Minecraft Server
players: 0/20 No players online
ping: 77.94 ms
```

> [!NOTE]
> You can also test the server by playing the game in multiplayer. Connect with a Minecraft Java client using <CLOUD_VM_IP>:<EXAMPLE_PORT_25565>.
